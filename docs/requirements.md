# DNA相補鎖ツール 要件定義書

作成日: 2026-08-17

## 1. 概要

DNA配列を入力すると、その逆相補鎖(5'→3')を計算して表示するWebツール。誰でも無料で気軽に使えるシンプルなツールとして公開し、なるべく多くの人に使ってもらうことを目標とする。

## 2. 対象ユーザー

研究者に限定せず、学生・教育関係者を含む一般ユーザーも対象とする。専門用語に偏りすぎない、わかりやすいUIを心がける。

## 3. 利用環境

- PCでの利用を前提とする(レスポンシブ対応は簡略化してよい)
- UI言語は日本語のみ

## 4. 技術構成

- フレームワーク: Next.js(App Router)
- デプロイ先: Vercel
- 配列の変換処理はすべてクライアントサイドで完結させる(配列をサーバーに送信しない。プライバシー配慮とレスポンス速度の両立)
- データベースは使用しない

## 5. 機能要件

### 5.1 入力

- DNA配列(A, T, G, C。大文字・小文字を許容)を入力できる
- FASTA形式(`>`ヘッダー行)にも対応する
  - 複数配列(複数の`>`ヘッダー)が貼り付けられた場合は、全ての配列をリスト化して順に変換・表示する
- ページに初めてアクセスした際、入力欄は空の状態にする(サンプルは自動投入しない)
- 「サンプル配列を入力」ボタンでサンプル配列(FASTA形式・複数配列)を入力欄に投入できる
- 「クリア」ボタンで入力欄と結果をリセットできる

### 5.2 変換の実行

- 入力欄の内容は自動変換せず、「相補鎖に変換する」ボタンを押したときにのみ変換を実行する
- ATGC以外の文字が含まれる配列はエラーメッセージを表示して弾く(該当配列・該当文字を明示する)
- FASTA内に複数配列がある場合、配列ごとに独立してバリデーション・変換を行う(一部の配列が不正でも他の配列は変換結果を表示する)

### 5.3 出力(配列ごとに以下を表示)

- **逆相補鎖(5'→3')**: メインの結果として、入力欄よりも視覚的に目立つスタイル(大きめのフォント・太字・アクセントカラーの背景と枠線)で表示する
- **mRNA表示切り替えオプション**: 入力配列を鋳型鎖とみなし、逆相補鎖(上記の結果)のT→Uを置換したものをmRNAとして表示する。トグルスイッチで切り替え
- **制限酵素認識部位のハイライト(オプション)**: メジャーな5種類をプリセットとして用意し、チェックボックスで対象酵素を選択できる
  - EcoRI(GAATTC)/ BamHI(GGATCC)/ HindIII(AAGCTT)/ XhoI(CTCGAG)/ NotI(GCGGCCGC)
  - 入力配列上での出現位置・件数をバッジ表示し、該当箇所を色付きハイライトする
  - 表示位置: 逆相補鎖(mRNA)結果ボックスの直下、かつ「塩基の色分け」セクションより上
- **補助情報**(結果の下に、常時表示。折りたたみはしない):
  - 塩基ごとの色分け表示(A/T(U)/G/Cを色分けしたピル表示)
  - 塩基構成比(積み上げバー+凡例)
  - 塩基対のペアリング表示(入力鎖 5'→3' と相補鎖 3'→5' を対にした「はしご」ビュー)
  - 配列長・GC含量(数値+GC含量はゲージバー付き)。配列長・GC含量はカード上部にも簡易表示する
- 各結果に「コピー」ボタンを設置し、表示中の配列をワンクリックでコピーできる

### 5.4 オプション設定の配置

- mRNA表示切り替え、制限酵素ハイライトのトグルは、DNA配列入力欄の右側(サイドバー領域)に、アイコン付きのカードとトグルスイッチで目立つように配置する
- 制限酵素ハイライトをオンにすると、対象酵素を選択するチェックボックス群が展開表示される

### 5.5 入力履歴

- ブラウザのlocalStorageに最大30件まで保存する(サーバーには送信しない)
- 保存内容: 配列本体、入力日時
- 表示位置: サイドバー、オプション設定の下
- 履歴項目をクリックすると入力欄に再利用できる
- 「履歴をクリア」ボタンで全履歴を削除できる

## 6. 非機能要件

### 6.1 SEO対策

- 適切な`title` / `description`メタタグを設定する
- OGPメタタグを設定し、SNSでの共有時にタイトル・説明・画像が表示されるようにする
- `sitemap.xml` / `robots.txt` を用意する

### 6.2 共有性

- クエリパラメータ(`?seq=...`)で配列を渡せるようにし、結果ページのURLをそのまま共有できるようにする

### 6.3 プライバシー

- 入力された配列はサーバーに送信せず、変換処理・履歴保存はすべてブラウザ内で完結させる

## 7. 画面構成

要件定義の過程でインタラクティブなモックアップを作成し、以下の構成で合意済み。

- **ヘッダー**: アクセントカラーの帯に、二重らせんの装飾・アイコン・タイトル・サブタイトルを配置
- **左カラム(メイン)**: DNA配列入力欄 → エラー表示 →「相補鎖に変換する」ボタン/サンプル/クリアボタン → 変換結果リスト(配列ごとにカード表示)
- **右カラム(サイドバー)**: mRNA表示トグル → 制限酵素ハイライトトグル(+酵素選択) → 入力履歴リスト
